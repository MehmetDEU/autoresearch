# TEAP Final Exam Grading Rubric (60 points total)

## Participation checklist (max 20)
- Count Yes on items 1-3 only:
  - 2 or 3 Yes -> 10 points
  - 1 Yes -> 5 points
  - 0 Yes -> 0 points
- Item 4 presentations:
  - If "number of times" is **2** -> participation total = **20** (full credit, ignore other rules)
  - Else if "I participated" checked -> add 10 points
  - Else if "I did not participate" -> add 0
- Cap participation at 20.

## Section I Q1-10 (1 point each, max 10)
Answers: 1A, 2B, 3B, 4A, 5A, 6B, 7A, 8B, 9B, 10A
Accept A/EAP or B/GE (case insensitive).

## Section II Q11-14 (3 points each, max 12)
Accept reasonable spelling variants:
- 11 Multidisciplinarity
- 12 Cross-disciplinarity (accept crossdisciplinarity)
- 13 Interdisciplinarity
- 14 Transdisciplinarity

## Section III Q15 (max 9)
UNESCO transversal skills definition in own words.
- 7-9: accurate core idea (transferable, not tied to one job/discipline, used across contexts)
- 4-6: partial
- 0-3: off-topic or empty
Deduct for meaning-changing grammar/spelling (reasonable, not harsh):
- minor typo: -0.5 each (max -2 on Q15)
- serious clarity/grammar issues: up to -2 additional

## Section III Q16 (max 9, 1.5 per domain)
Six domains (accept near-equivalents):
1. Critical and innovative thinking
2. Interpersonal skills
3. Intrapersonal skills
4. Global citizenship
5. Media and information literacy
6. Physical and mental well-being
Scoring per domain: 1 pt name + 0.5 pt relevant example.
Accept synonyms (e.g. collaboration for teamwork, cognitive for critical thinking if clear).

## Total
participation + section_i + section_ii + section_iii (max 60)

Return JSON only for each paper.
